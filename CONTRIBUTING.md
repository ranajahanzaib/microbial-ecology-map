# Contributing

Contributions are welcome, including bug reports, documentation improvements, and code changes.

## Development setup

1. Fork and clone the repository:

   ```bash
   git clone https://github.com/ranajahanzaib/microbial-ecology-map.git
   cd microbial-ecology-map
   ```

2. Install the dependencies listed in the [README](README.md#run-locally).
3. Create a branch for the change.
4. Make the change and add or update tests when behavior changes.
5. Run the checks documented in the README, then open a pull request with the purpose and relevant context.

## Contribution guidelines

- Keep scientific methods, source records, and value semantics explicit.
- Do not invent sample metadata, locations, or analysis results.
- Keep credentials, local environment files, generated databases, and source-response caches out of commits.
- Use focused changes and include documentation updates for user-visible behavior.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting issues

Use the repository's issue templates for bug reports and feature requests. Report security vulnerabilities privately using the process in [SECURITY.md](.github/SECURITY.md).
